# Installation
- Open Terminal/Command Prompt in the folder this file was downloaded
- Type ./Patchsu-cli and press enter
- Follow instructions that are present in CLI tool

This will create another folder in your selected location with automatic .desktop files for all 3 systems. It will also auto-bind to your existing osu!lazer folder, which would sync everything you have on clean lazer to Patchsu.

For now there won't be singular .exe that you can launch and it will do everything for you, because this 'project' somehow got too ambigous with A LOT of patches very quickly
